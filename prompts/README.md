# Prompt pack

Every prompt from the session, ready to copy. Each one assumes your assistant has your three files loaded (voice, ICP, product; see `01-voice-file.md` through `03-product-file.md`). Replace the brackets. If your assistant has a projects or folders feature, keep the three files there so you never paste them again.

| File | Use it when |
| --- | --- |
| [00-start-here.md](00-start-here.md) | Right after the session. One prompt that walks you through the three files, a brief and a first email. |
| [01-voice-file.md](01-voice-file.md) | Once. Turns your best emails into a style guide the assistant writes from. |
| [02-icp-file.md](02-icp-file.md) | Once. Who buys, who doesn't, trigger events, disqualifiers. |
| [03-product-file.md](03-product-file.md) | Once. What you sell in the buyer's words, with proof and the promises you can't make. |
| [04-account-brief.md](04-account-brief.md) | Before any first call. Sourced one-page brief and a "why now" sentence. |
| [05-first-touch.md](05-first-touch.md) | Writing a cold or warm first email from a brief. |
| [06-call-prep.md](06-call-prep.md) | Five minutes before a discovery call. |
| [07-objection-roleplay.md](07-objection-roleplay.md) | Rehearsing a hard conversation. |
| [08-follow-up.md](08-follow-up.md) | Ten minutes after a call, from the transcript. |
| [09-proposal-draft.md](09-proposal-draft.md) | Proposal or business case from a template plus the call. |
| [10-deal-review.md](10-deal-review.md) | Before the pipeline review. The skeptic. |
| [11-weekly-summary.md](11-weekly-summary.md) | Friday. Wins, risks, asks. |

For the plugin version of the research-to-outreach exercise, use the [Prospector companion guide](../program/PROSPECTOR.md). The prompts above also work without the plugin.

The rule that goes with all of them: the AI drafts, you send.
