# Voice file

Run once. Save the output as `voice.md` where your assistant loads it automatically.

```
Here are five emails I've sent that I think are good, and three I'd never send.
[paste them, label GOOD and BAD]
Write a one-page style guide for writing as me: typical sentence length, how I open and close,
words and phrases I use, words I never use, how formal I am with [who you sell to],
how I handle a no. Then draft a two-line test email in my voice so I can check it.
```

If the test email doesn't sound like you, say what's off ("too chirpy", "I never say 'reach out'") and run it again. Three rounds is normal.
