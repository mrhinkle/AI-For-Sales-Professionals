https://engineering.atspotify.com/2025/5/incident-report-spotify-outage-on-april-16-2025
Spotify reported an Envoy perimeter failure following a filter-order change, compounded by a mismatch between heap and Kubernetes memory limits. It reported fixes and planned rollout/monitoring improvements. This concerns perimeter traffic; it does not establish a service-mesh gap or show that Linkerd would have prevented the outage. It is not a fresh November 2026 trigger.
