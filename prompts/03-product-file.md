# Product file

Run once. Save as `product.md`. Have product marketing check it.

```
Write a one-page product file for [product] that a new sales hire could read in five minutes.
Sources: [paste the website copy, a datasheet, two case studies, the pricing page or guardrails].
Sections: what it does in one sentence a [buyer] would say; the three problems it fixes and
how the buyer describes each one; proof we can name (customers, numbers, quotes with sources);
how it's priced and what I'm allowed to say about discounts; the two competitors we meet most
and the honest one-line difference; and a section called "Never promise" for anything
unreleased or unsupported.
```
